# Catálogo de activos

## Logo

`logo/` contiene la versión aprobada del logotipo para fondos claros y oscuros, el símbolo `h`, el SVG para BIMI, favicon e iconos PNG.

## Paleta

`paleta/` contiene la lámina de colores en SVG editable y PNG de consulta.

## Portadas

Cada propuesta contiene:

- `16x9/`: fondos para presentaciones;
- `letter/`: portadas para documentos;
- `editable.svg`: composición editable;
- `fondo.svg` y `fondo.png`: arte listo para usar como fondo.

Las familias son `01-blanca`, `02-celeste` y `03-oceano`.

## Papelería

`papeleria/` contiene membrete, interior, marca de agua y pies de página para documentos y presentaciones en SVG y PNG.

## Previsualizaciones

`previews/` reúne láminas rápidas para comparar portadas y revisar la identidad sin abrir cada archivo maestro.
